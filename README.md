# ⚙️ Local Installation

Clone the repository

```bash
git clone https://github.com/S1A8H3I4L/Sahil-Portfolio.git
```

Install dependencies

```bash
npm install
```

Create environment variables

```bash
cp .env.local.example .env.local
```

Run development server

```bash
npm run dev
```

Open

```
http://localhost:3000
```
